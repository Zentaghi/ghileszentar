# Portfolio — Ghiles Zentar

Portfolio personnel de Ghiles Zentar, étudiant en informatique et électronique à l'Université de Rouen Normandie.

## Mise à jour

Le contenu principal est centralisé dans `data/portfolio.json`.

Après une modification sur la branche `main`, le workflow GitHub Actions republie automatiquement le site via GitHub Pages.

## Structure

- `index.html` — page principale
- `assets/style.css` — design responsive
- `assets/app.js` — rendu dynamique
- `data/portfolio.json` — projets, compétences et formation
- `.github/workflows/pages.yml` — déploiement automatique
